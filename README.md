# Projeto GEAP

Painel de atividades escolares feito com HTML, CSS e JavaScript puro.

## Como executar

Abra o arquivo `index.html` no navegador. Não é necessário instalar dependências ou iniciar um servidor.

## Funcionalidades

- Visão do aluno com atividades pendentes, entregues, avaliadas e atrasadas.
- Filtros por situação e busca por atividade.
- Envio de atividades de demonstração pelo painel do aluno.
- Visão do professor com entregas organizadas por aluno e opção para avaliar entregas.
- Alterações de status persistidas no armazenamento local do navegador.

Os dados são demonstrativos e ficam salvos somente no navegador utilizado.
