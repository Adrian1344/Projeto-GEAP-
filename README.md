# Projeto GEAP

Painel docente de atividades escolares feito com HTML, CSS e JavaScript puro.

## Como executar

Abra `index.html` no navegador. Não é necessário instalar dependências ou iniciar um servidor.

## Funcionalidades

- Criar, editar, excluir, pesquisar e filtrar atividades.
- Acompanhar o estado das entregas por aluno: pendente, entregue, avaliada ou atrasada.
- Filtrar a lista de entregas de cada atividade e atualizar a situação individual do aluno.
- Consultar um resumo das entregas de todas as atividades e turmas.
- Salvar atividades e situações no armazenamento local do navegador.

As turmas e entregas iniciais são dados demonstrativos; as alterações ficam salvas apenas no navegador utilizado.
